# Learn
My personal online reading library
**A Note About the Library**

The books currently available on this website are part of the initial testing phase. Some of these files may be temporary and will be removed as the library develops.

The long-term goal is to build a collection of books that are freely available to read and share, including public-domain works, open-access publications, and books released under licences that permit redistribution.

This is a personal learning project, and the library will gradually evolve.
